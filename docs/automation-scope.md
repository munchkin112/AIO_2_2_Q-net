## 에이전트가 맡는 범위

추천 에이전트는 제공된 프로필과 공식 자료를 바탕으로 자격증 탐색을 돕습니다. 실제 조회와 API 실행은 Python이 담당합니다. 상태는 요청 단위로 관리하며, 화면에서 보관한 프로필을 장기 Agent 기억으로 취급하지 않습니다.

자동 재시도는 무제한이 아닙니다. 현재 추천 그래프는 모델 최대 5회·도구 최대 6회, 일시 오류 재시도 1회·결과 또는 인자 보완 1회로 제한합니다. 정상 조회 후 후보가 없는 상태와 도구·검증 오류는 구분합니다.

## 현재 범위 밖의 작업

- 공식 응시자격의 확정 판정과 합격·취업 보장
- 원서접수·결제 대행
- 사용자가 요청하지 않은 Calendar 일정 생성·변경
- Supervisor 기반 멀티에이전트, 전용 벡터 RAG, 장기 메모리, 시험 준비 로드맵

Q-Net 공식 자료의 수집·DB 적재는 별도 관리 작업입니다. 일반 화면 조회나 추천 요청이 공유 DB의 테이블 구조를 바꾸거나 자료를 새로 수집하는 작업은 아닙니다.
